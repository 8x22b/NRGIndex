Найденные фото

Фон вырезается автоматически, акценты подбираются по банке. 🍌 — если ракурс плохой или фон удалился криво.

Base URL — корень API без /chat/completions. Запросы идут на {base}/chat/completions и {base}/audio/transcriptions. Для OpenRouter аудио отправляется JSON-ом, для остальных — multipart, как в OpenAI API. Пустое поле — значение по умолчанию.

Прокси прозрачный: разбор текста и распознавание голоса идут через него целиком (HTTPS туннелируется через CONNECT, ключ и данные прокси не видит). Поддерживаются http://, https:// и socks5://, логин и пароль — прямо в адресе. Поиск фото ходит напрямую. Пароль в поле показан как *** — не трогай его, и он сохранится. Можно задать и через AI_PROXY_URL в env.

Google CSE — первый источник фото (бесплатно 100 запросов/день). Без ключа работают DuckDuckGo + Open Food Facts + Wikimedia. Ключ: console.cloud.google.com → Custom Search API → API key; CX: programmablesearchengine.google.com → Search entire web + Image search. Можно задать и через GOOGLE_CSE_KEY / GOOGLE_CSE_CX в env.

Gemini (Nano Banana) перерисовывает банку на белом фоне под прямым ракурсом — кнопка «🍌» рядом с фото в кабинете. Ключ бесплатный: aistudio.google.com → Get API key, free tier хватает. Можно задать и через GEMINI_API_KEY / GEMINI_IMAGE_MODEL в env.

«Откатить» возвращает объект в состояние до действия. Откатывать можно по порядку: если объект менялся позже, сначала откатите более свежую запись.

Запросы к ИИ и распознаванию речи: модель, токены, цена и время. Ошибки — серверные (5xx), в том числе сбои ИИ. Журнал действий — на вкладке «Журнал».
