# NRG / INDEX

Статический коллективный тирлист энергетиков.

## Где менять данные

Все участники, напитки, оценки и отзывы лежат в `data.js`.

- `participants` — участники.
- `drinks` — карточки энергетиков.
- `ratings` — оценка конкретного участника и его текстовое мнение.
- Допустимые тиры: `S`, `A`, `B`, `C`, `D`.

Сводный рейтинг считается автоматически только по тем участникам, которые уже выставили оценку.

## Локальный просмотр

```bash
python3 -m http.server 8080
```

Затем открыть `http://localhost:8080`.
